Put your Autos and TeleOps here, in the `robot.opmode` package.

To start, copy [`BoilerplateAuto.java`](../../../../examples/ftc/BoilerplateAuto.java) or
[`BoilerplateTeleOp.java`](../../../../examples/ftc/BoilerplateTeleOp.java) from `examples/ftc/` into this folder,
rename the class, and give it an `@Autonomous`/`@TeleOp` name.
See [`robot/README.md`](../../../README.md) for how `AutoBase` and `TeleOpBase` work.
