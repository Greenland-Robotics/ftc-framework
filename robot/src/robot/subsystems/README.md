Put your subsystems here, one per mechanism (e.g. `Intake.java`, `Arm.java`), in the `robot.subsystems` package.

A subsystem owns its hardware and offers behaviors (`intake.collect()`) and sensor checks (`intake.hasSample()`).
Register each one in [`Robot.java`](../Robot.java). See [`examples/ftc/Intake.java`](../../../../examples/ftc/Intake.java)
and [`framework/README.md`](../../../../framework/README.md#subsystems).
